# SPARK Android Wallet

Kotlin + Gradle native Android app implementing the SPARK wallet.

Setup and run instructions: see the root [README.md](../README.md#android-wallet).

Implements the wire formats and crypto defined in [docs/](../docs/) — see in particular
[transaction-format.md](../docs/transaction-format.md), [certificate-format.md](../docs/certificate-format.md),
[purse-token-format.md](../docs/purse-token-format.md) and [crypto.md](../docs/crypto.md).
